# Sistema de Cadastro de Alunos

Projeto desenvolvido em Java para praticar Programação Orientada a Objetos (POO).

## Funcionalidades

- Cadastro de alunos
- Cadastro de turma
- Cadastro de notas
- Cálculo de média
- Controle de frequência
- Validação de dados com Regex
- Uso de LocalDate para data de nascimento
- Uso de ArrayList

## Tecnologias

- Java
- POO
- Regex
- LocalDate
- ArrayList
